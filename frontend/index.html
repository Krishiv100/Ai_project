Model architecture

What QCAS-DF analyzes

The model combines complementary evidence instead of relying on one visual cue.

01

Quality estimation

Estimates input degradation so the spectral analysis can adapt to image quality and compression.

02

Spatial differences

Uses local average-difference texture cues to expose subtle spatial inconsistencies.

03

Adaptive spectrum

Transforms YCbCr channels to frequency space and learns ordered low/mid/high boundaries.

04

Dynamic fusion

Weights spatial and spectral features based on content and estimated input quality.

Important

Research prototype, not forensic proof.

A prediction is a model estimate. Performance can change with compression, unseen manipulation methods, image quality, dataset shift and face-detection failures. Use results as supporting evidence, not as definitive authentication.
